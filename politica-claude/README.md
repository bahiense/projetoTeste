# Professor de Política — dentro do Claude

A mesma ideia do app `politica-android/`, mas rodando dentro do Claude, como
artifact: as aulas são escritas pelo plano do Claude de quem usa, sem chave
de API e sem custo extra.

Abrir: https://claude.ai/artifact/Fexq3SMKpPT7jYdWLyi3Jw (no app do Claude ou em claude.ai).

- O PDF é aberto no próprio aparelho (pdf.js). Cada página vira duas imagens
  (metades de cima e de baixo, para a letra pequena chegar legível) e vai ao
  Claude em lotes de três páginas, com o texto do PDF quando houver.
- A transcrição dos slides é a base de tudo: plano, um pedido por módulo,
  autores de três em três, conceitos e cronologia, debates, questões e revisão.
  Cada parte é guardada assim que fica pronta, então dá para continuar de onde
  parou (por exemplo, quando acaba a cota do plano).
- As lições, o progresso e as conversas ficam no banco do artifact, numa pasta
  particular de cada pessoa.
- Diferença para o APK: aqui o professor não pesquisa na web; usa o próprio
  conhecimento e o que está nos slides.
