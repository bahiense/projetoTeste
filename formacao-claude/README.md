# Formação do Pensador

App dentro do Claude (artifact): https://claude.ai/artifact/V1oFFYvRYkonzx5QVfEceo

Irmão do Professor de Política (`politica-claude/`), com o mesmo método de aula,
mas com um mestre de várias áreas (filosofia, teologia reformada, ciência
política, história, literatura) e o objetivo de formar um pensador.

- A aula parte de um **assunto escrito pelo aluno** (o mestre primeiro escreve o
  material-base, que faz o papel do PDF), de um **PDF** ou de um **texto colado**.
- Dois tipos: aula completa (semana, de segunda a sexta, com palavras difíceis,
  quem é quem e teste no fim de cada módulo) ou aula para leigos (uma só, neutra).
- Cada módulo termina com "Para pensar como um intelectual": tese, pressupostos,
  objeção mais forte e resposta.
- As cópias usam o mesmo formato do Professor de Política, então o APK
  Ciência Política (`politica-android/`) importa as aulas daqui também.
