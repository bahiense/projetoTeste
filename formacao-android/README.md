# Formação do Pensador — app Android

**Para instalar:** https://github.com/bahiense/projetoTeste/releases/download/formacao-apk-latest/formacao.apk

Leitor das aulas do Formação do Pensador (`formacao-claude/`, dentro do Claude:
https://claude.ai/artifact/V1oFFYvRYkonzx5QVfEceo). Mesmo código do
`politica-android/`, com pacote, nome, cores, link de atualização e o mestre
próprios. As aulas entram pelo arquivo que o Claude baixa (Importar aula,
Abrir com ou Compartilhar), com cópia automática em Downloads e para o Drive.

Assina com a mesma chave do Ciência Política (segredos POLITICA_KEYSTORE_*),
então as versões novas instalam por cima.
